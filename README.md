# ПринтСелект — Next.js

Полноценный адаптивный проект витрины и конструктора принтов. Подходит для импорта в CodeSandbox.

## Запуск

1. Установите зависимости: `npm install`
2. Запустите проект: `npm run dev`
3. Откройте `http://localhost:3000`

Для CodeSandbox достаточно импортировать всю папку проекта. Переменные окружения необязательны; их примеры находятся в `.env.example`.
